# M4 first-person animation pack

Both supplied uploads are byte-identical and are kept as two selectable slots, labelled v1 and v11 after the uploaded filenames. They are not distinct weapon designs.

M4 - FPS Weapon Animations Pack (v.1) by BarcodeGames.
Source: https://sketchfab.com/3d-models/m4-fps-weapon-animations-pack-v1-662fc74dda2646cfb48fc610705768ef
License: CC BY 4.0 https://creativecommons.org/licenses/by/4.0/

Original models and embedded textures are unchanged. Runtime trims the shared timeline offsets from the Draw, Fire, Reload, Reload_Empty and Holster clips and positions the view using the authored FPS_Camera_j_01 joint. Fire is sped up for gameplay. Each slot has its own 30-round magazine; reserve ammunition is unlimited.
