# San Aurelio

משחק עולם פתוח בתלת־ממד שרץ בדפדפן: עיר חוף שלמה, נהיגה עם פיזיקה, מרדפים משטרתיים, משימות ורדיו.

אין צורך בהתקנה, בבנייה או בקבצי מדיה. העיר, המכוניות, הדמויות, הצלילים והמוזיקה נוצרים בקוד בכל טעינה. הקוד הוא JavaScript רגיל עם [Three.js](https://threejs.org/) r128 מ־CDN.

> כל השמות, המותגים והמקומות במשחק בדיוניים. הפרויקט לא קשור לאף מפתח או סדרת משחקים קיימת.

---

## הרצה מקומית

הכי פשוט: לפתוח את `index.html` בדפדפן. זה עובד גם ישירות מהדיסק, כי אין טעינת קבצים חיצוניים מלבד Three.js והגופנים.

אם אתם מעדיפים שרת מקומי:

```bash
npx serve .
# או
python3 -m http.server 8080
```

ואז לגלוש ל־`http://localhost:8080`.

**דרישות:** דפדפן עם WebGL (Chrome, Edge, Firefox או Safari עדכניים), מקלדת ועכבר. מומלץ לשחק עם אוזניות.

## פרסום ב־GitHub Pages

1. דוחפים את התיקייה לריפו:
   ```bash
   git init
   git add .
   git commit -m "San Aurelio v1.0"
   git branch -M main
   git remote add origin https://github.com/<USER>/<REPO>.git
   git push -u origin main
   ```
2. בריפו נכנסים ל־**Settings → Pages**.
3. תחת **Build and deployment** בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ושומרים.
4. אחרי דקה בערך המשחק זמין ב־`https://<USER>.github.io/<REPO>/`.

הקובץ `.nojekyll` כבר בריפו, כך ש־GitHub מגיש את הקבצים כמו שהם.

## מה יש במשחק

**העיר**
- רשת של 12×12 בלוקים על אי: דאונטאון עם גורדי שחקים, שכונות מגורים, וילות עם גגות רעפים, חמישה פארקים, חוף, דקלים והרים ברקע.
- כל העיר נוצרת מזרע (seed) קבוע, כך שהיא זהה בכל טעינה.
- הבניינים מאוחדים לכמה רשתות (meshes) בודדות, והצמחייה, הפנסים והרמזורים מצוירים ב־instancing. כך העיר כולה עולה בכמה עשרות קריאות ציור בלבד.

**יום ולילה**
- יום שלם במשחק נמשך 20 דקות אמיתיות.
- שמש וירח, שמיים עם שקיעה, כוכבים, וצללים דינמיים שעוקבים אחרי השחקן.
- בלילה נדלקים חלונות, פנסי רחוב ושלטי חוצות.

**נהיגה**
- מודל "אופניים" עם אחיזה צידית: הרכב מחליק כשמגזימים, ובלם היד מאפשר דריפט.
- הגבלת תאוצה צידית לפי מהירות, ומשקל שונה לכל רכב.
- התנגשויות עם סיבוב, נזק מצטבר, עשן, שריפה ופיצוץ.
- שישה דגמים בדיוניים: סדאן, ספורט, SUV, ואן, מונית וניידת.

**תנועה ותושבים**
- נהגים שנוסעים בנתיב הימני, עוצרים ברמזורים ושומרים מרחק.
- הולכי רגל על המדרכות שבורחים מסכנה.
- רכבים חונים שאפשר לקחת, ונהגים שאפשר להוציא מהרכב.

**משטרה**
- חמש רמות מרדף. השוטרים מנווטים ברשת הרחובות, מתקרבים לעצירה ויורים מרמה 3.
- מרמה 4 מצטרף מסוק עם זרקור.
- כדי להתחמק צריך לצאת מטווח הראייה שלהם לפרק זמן שתלוי ברמת המרדף.

**משימות**
- **משלוח לילה:** איסוף ומסירה בזמן מוגבל.
- **מרוץ רחוב:** שמונה נקודות ביקורת ושעון.
- **הכספת של הבנק המרכזי:** שוד, מרדף ובריחה למחבוא.
- בנוסף יש מזומנים וערכות בריאות מפוזרים בעיר.

**ממשק**
- מפה קטנה מסתובבת עם ניווט GPS לאורך הרחובות.
- מפה מלאה שבה קליק מסמן יעד.
- מד מהירות עם הילוכים, התראות, ושמות שכונות.
- התפריט הראשי בנוי כגשר שלטים של כביש מהיר, מעל העיר החיה ברקע.

**סאונד**
- הכול מסונתז ב־Web Audio: מנוע עם הילוכים, צמיגים, צופר, סירנה, מסוק, פיצוצים ויריות.
- שלוש תחנות רדיו עם מוזיקה פרוצדורלית: סינת׳וויב, לו־פיי והאוס.

**שמירה**
- הכסף, המשימות שהושלמו וההגדרות נשמרים ב־`localStorage`.

|---|---|---|---|
| `W A S D` | תנועה | `W` | גז |

| `רווח` | קפיצה | `A D` | היגוי |
| עכבר | מבט מסביב | `רווח` | בלם יד |

## מבנה הקוד

```
index.html          מסכים: טעינה, תפריט, HUD, עצירה, מפה
css/style.css       כל העיצוב
js/config.js        קבועים, מפרטי רכבים, רמות איכות, פונקציות עזר
js/audio.js         Sound (אפקטים) + Radio (סיקוונסר מוזיקה)
js/world.js         יצירת העיר, שמיים, תאורה, יום/לילה, התנגשויות, גרף רחובות
js/vehicle.js       בניית רכבים, פיזיקה, נזק, התנגשויות בין רכבים
js/characters.js    שלד דמות, שחקן, הולכי רגל
js/ai.js            תנועה, רכבים חונים, משטרה, מסוק, מערכת מרדף
js/fx.js            חלקיקים: פיצוצים, עשן, אש, ניצוצות
js/missions.js      משימות, משואות, איסופים
js/ui.js            HUD, מפה קטנה, מפה מלאה, פאנלים
js/main.js          קלט, מצלמה, לולאת המשחק, מוות/מעצר, שמירה
```

הסקריפטים נטענים לפי הסדר הזה ב־`index.html` וחולקים מרחב גלובלי אחד, בלי מודולים ובלי bundler.

## כוונון מהיר

- **מהירות ותאוצה של רכבים:** `VEHICLES` בקובץ `js/config.js`.
- **גודל העיר:** `CITY.GRID` ו־`CITY.BLOCK` באותו קובץ.
- **עומס תנועה והולכי רגל לפי איכות:** `QUALITY`.
- **אורך היממה:** `World.daySpeed` בקובץ `js/world.js`.
- **קושי המשטרה:** `Wanted.thresholds`, מספר הניידות ב־`Wanted.update`, וזמן ההתחמקות `need`.
- **משימה חדשה:** מוסיפים רשומה ל־`Missions.defs` ומקרה ב־`Missions.build`. כל שלב הוא `goto` (הגעה ליעד) או `lose` (התחמקות).

## ביצועים

על מחשב נייד חלש כדאי לבחור איכות **נמוכה** בהגדרות. היא מכבה צללים, מקצרת את טווח הראייה ומפחיתה תנועה. אפשר להפעיל מונה FPS מאותו מסך.

## רעיונות להמשך

נשק ויריות של השחקן, כניסה לבניינים, גשם ומזג אוויר, אופנועים, שליטה במגע לנייד, טלפון במשחק, ועוד משימות עם עלילה.
